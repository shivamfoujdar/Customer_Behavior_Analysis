# Customer Shopping Behavior Analysis

An end-to-end data analytics project focused on understanding customer shopping behavior and generating actionable business insights.

### 🛠️ Tools & Technologies
- Python
- Pandas & NumPy
- SQL / PostgreSQL
- Power BI
- Data Cleaning & EDA
- Customer Segmentation

### 🎯 Project Objective
To analyze customer purchasing patterns, product performance, subscription behavior, discounts, shipping preferences, and customer segments to support data-driven business decisions.
